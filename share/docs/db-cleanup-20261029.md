## 테이블·컬럼 판단

- ULTARY 테이블 44개 모두 현재 mapper/서비스에서 참조된다. `ultary_feed_pet`, `ultary_story_mention`, `ultary_story_text`, `ultary_user_link` 등 현재 비어 있는 테이블도 기능에서 사용하므로 삭제하지 않았다.
- 실제 DB 컬럼을 런타임 Java/XML의 참조와 비교했다. SQL에서 명시적으로 이름이 나오지 않는 `ultary_story_view.story_view_id`, `viewed_at`은 각각 자동 증가 PK와 자동 생성 조회 시각이며, 조회 기록 생성 시 DB가 값을 저장하므로 보존했다.
- 옛 펫 태그 표시를 없앴어도 `ultary_pet.mention_id` 등은 내부 호환 응답·언급 처리에서 여전히 참조된다. 컬럼만 삭제하면 현재 배포된 SQL이 실패하므로 미사용으로 분류하지 않았다.
- 이번 조사에서 기능·기록에 영향 없이 삭제할 수 있다고 확인된 테이블/컬럼은 없어 DDL 삭제를 실행하지 않았다.

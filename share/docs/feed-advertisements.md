# 메인 광고 피드

- 링크태그 상품 전용 계정 6129(@sagepet), 6130(@cozypet), 6131(@walkwear), 6132(@dailycare), 6133(@softcare)를 `FeedAdvertisementPolicy`에 명시했다. 닉네임 변경과 무관하게 작성자 번호로 분류한다. 계정을 추가하면 이 정책을 수정한다.
- 이 계정이 쓴 피드는 단건·울타리·검색 상세·관리자 미리보기 등 공통 Feed 응답에 `advertisement=true`를 포함하고, 이미지 위 프로필 행 오른쪽 끝에 굵은 `[광고]`를 표시한다. 원문 DB content에는 접두사를 덧붙이지 않아 수정·글자 수·해시태그 처리를 유지한다.
- 일반 유저가 상품 링크태그를 사용한 후기에는 광고 표시를 붙이지 않는다.
- 메인 일반 타임라인과 일반 추천에서는 전용 판매자 계정 피드를 제외한다. 기존 상품 약 30% 분산은 제거하고 작성자 분산은 유지한다. 검색 그리드에는 별도 광고를 삽입하지 않는다.
- `GET /api/v1/main/feeds/advertisements` (BFF `/api/main/feeds/advertisements`)는 팔로우 여부와 관계없이 전용 판매자의 공개 계정·전체공개·활성 미디어 피드 중 승인된 상품 링크태그가 연결된 피드를 가져온다. 본인·차단·정지·탈퇴·삭제·비공개는 기존 추천 후보 조건으로 제외한다.
- 후보를 한 번 섞어 최대 50개 배열로 반환한다. FE는 메인 세션과 함께 이 순서를 보관하고 일반 글 4개, 5개 간격을 번갈아 적용해 하나씩 삽입한다. 타임라인에서 추천으로 넘어가거나 다음 페이지를 불러와도 간격을 이어간다.
- 한 메인 세션 안에서 같은 광고 ID는 한 번만 사용한다. 후보가 소진되거나 부족하면 일반 피드만 계속 표시한다. 광고 요청만 실패했을 때도 일반 피드는 정상 표시한다.
- SPA 뒤로가기에서는 광고 순서를 유지하고 메인 새로고침 시 새로운 후보 순서를 가져온다. 추가 노출 기록 DB는 없다. 기존 광고 카드의 좋아요·댓글·수정·삭제도 메인 세션 캐시에 반영한다.
- DB 스키마·원문 변경은 없다. FE·BE 재배포가 필요하다.

검증: BE 광고 자격·타임라인 분리·광고 플래그·공개 범위 및 차단 회귀 검사, FE 4/5 간격·중복 제거·페이지 추가 시 접두 순서 유지·세션 보존 검사.

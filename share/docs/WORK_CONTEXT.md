## 2026-10-19 · Cursor → Codex

- 앞으로 ULTARY 개발은 Cursor에서 Codex로 전환하여 이어간다.
- `ultary-api`(Spring Boot Backend)와 `ultary-web`(Next.js Frontend + BFF)은 하나의 서비스이므로 함께 확인한다.
- 판단 기준은 미커밋 변경을 포함한 현재 코드와 최신 `share/` 문서다. Git 이력은 설계 변화와 개발 의도를 이해하는 참고자료로 사용한다.
- `share/`는 두 저장소에 동일하게 미러링하는 공통 Source of Truth다.
- 이번 체크포인트는 Gemini 태그 추천·게시글/댓글/답글 모더레이션, 최근 검색 태그 이력, 공통 태그 카탈로그, 본문 100자 제한(schema v31)까지 포함한다.
- Codex는 두 저장소의 구조와 연동 관계를 분석했다. 발견한 불일치는 아직 수정하지 않았으며, 실제 수정은 사용자 확인 후 시작한다.
- 피드 수정의 form/JSON 불일치, 펫 태그 승인·거절 Spring API 누락, 공유 피드의 게스트 처리·파일 접근, 단건 피드 차단 검사, 이전 공통 타입을 우선 확인한다.
- 스토리 24시간 만료는 테스트 목적으로 비활성화되어 있다. 실제 SMS 발송과 `/write/*`, 공통 `/settings` API는 미완성이다.
- 이번 인계·커밋 작업에서는 빌드·테스트·DB 마이그레이션·실제 Gemini 호출을 실행하지 않았다. 실행 검증과 실제 DB schema v31 적용 여부 확인은 별도 작업이다.

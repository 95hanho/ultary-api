# 메인 목록 유지와 명시적 재조회

2026-11-03 보완: 스토리 읽음 기록이 성공하면 메인 스토리 메타를 무효화한다. 메인 복귀 시 스토리 보유자 목록만 한 번 갱신하며 피드·광고·페이지 커서·스크롤은 유지한다. 읽음 완료 후에도 내 링이 고정되거나 경계선이 남는 것을 방지한다. 이 정렬 변경은 BE `latestStoryAt` 집계 응답과 함께 반영한다.

2026-11-02 적용. FE 배포만 필요하며 DB·BE API 변경은 없다.

- 메인 타임라인·추천 목록, 각각의 다음 페이지 커서, 스토리 목록·내 정보와 세로 스크롤 위치를 브라우저 런타임 메모리에 보관한다.
- 같은 탭에서 다른 화면을 다녀오거나 홈으로 이동하면 기존 목록을 사용한다. 이미 불러온 페이지를 다시 요청하지 않고 보관한 커서부터 추가 조회한다.
- 메인에 있는 상태에서 홈 버튼이나 홈 로고를 다시 누르면, 메인 초기 조회·추가 페이지 조회가 진행 중이지 않을 때만 처음부터 재조회한다. 스크롤은 맨 위로 이동한다. 다른 화면의 홈 버튼은 일반 복귀 동작이다.
- 초기 조회 4개 중 하나가 먼저 실패해도 나머지 요청이 모두 끝날 때까지 새 홈 조회를 허용하지 않는다. 홈 연속 클릭·무한 스크롤과 재조회 간 중복 요청을 차단한다.
- sessionStorage/localStorage에 목록을 저장하지 않는다. 브라우저 새로고침·새 문서에서는 메모리가 초기화되어 반드시 다시 조회한다. 로그인·로그아웃도 기존 전체 문서 이동을 유지한다.
- 수정 완료 응답은 보관된 해당 카드만 갱신한다. 좋아요·저장·고정·댓글 수·삭제·현재 카드의 AI 조치도 캐시에 반영한다. 목록 순서와 커서는 유지한다. 다른 곳에서 추가된 게시글 등 새 목록은 명시적 재조회 시 확인한다.
- 일반 메인 복귀는 보관된 세로 스크롤을 복원한다. 게시글 수정 복귀에는 기존 카드 기준 복원을 우선하며 사용자가 직접 스크롤하면 자동 복원을 멈춘다.

메인 데이터는 서버 렌더링에서 공유하지 않는다. 서버 스냅샷은 항상 비어 있으며 화면의 데이터는 브라우저 조회 결과만 사용한다.

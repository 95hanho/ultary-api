# 콘텐츠 수정용 서비스 계정

- 예약된 사용자 계정 `user_no=100`: 이름 `관리자`, 닉네임태그 `@administrator`.
- 일반 사용자 로그인으로 접근하며, 로그인한 principal의 userNo가 100인 경우 다른 작성자의 게시글·댓글·답글도 수정할 수 있다. 닉네임 문자열이나 클라이언트가 보낸 작성자 번호로 권한을 부여하지 않는다.
- FE 수정 메뉴와 편집 진입 검사, BE 게시글 사전 AI 검사 진입 및 실제 수정 트랜잭션에 같은 정책을 적용한다. 다른 일반 계정은 본인 콘텐츠만 수정한다.
- 원래 작성자 번호를 유지한다. 게시글의 펫 선택은 원래 작성자의 펫을 조회·검증한다. 댓글·답글의 언급 검증과 AI 검사 작업도 원래 작성자를 기준으로 유지하며 수정 실행 계정은 서버 로그에 기록한다.
- 삭제 권한, 공개 범위·차단에 따른 조회 제한, AI 검사 및 입력 검증은 유지한다. 별도의 관리자 로그인 계정/권한을 부여한 것은 아니다.
- `administrator`는 요청에 따라 직접 지정한 13자 운영 닉네임이다. 일반 가입·닉네임 변경의 1~10자 규칙을 완화하지 않았다.
- DB의 100번 계정 이름/닉네임은 2026-11-02에 직접 반영했다. 스키마 변경은 없다. 수정 기능 반영에는 FE·BE 재배포가 필요하다.

검증: `FeedEditIntegrationTest`에서 100번의 타인 게시글·댓글·답글 수정, 원래 작성자·펫 유지, 일반 계정의 타인 수정 거부, 삭제 권한 비확대를 확인한다. 기존 댓글 언급 테스트도 함께 실행한다.

# 개발 데이터 안내

현재 시연 데이터는 2026-10-29 CDN 개편에 맞춰 DB에서 관리한다. 실행 가능한 공용 시드는 제공하지 않는다.

기존 MariaDB 10.1 시드 5개는 옛 스키마·닉네임·펫 태그·삭제된 CDN 파일을 사용하므로 제거했다. 재실행하면 현재 작성글·연관 데이터와 충돌하거나 삭제한 이미지 주소가 다시 들어갈 수 있다. 과거 내용은 Git 이력에서 확인할 수 있다.

- 스키마를 준비할 때는 `../schema/mariadb_10_1/`의 문서를 따른다.
- 현재 데이터를 다른 DB로 옮길 때는 접근이 제한된 DB 백업을 사용한다. 실제 회원·비밀번호 해시·토큰·DM을 공용 저장소에 내보내지 않는다.
- 데이터 정리 결과는 `../../docs/db-cleanup-20261029.md`와 `../../docs/cdn-refresh-20261029.md`를 참고한다.
